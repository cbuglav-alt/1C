# Чек-лист: НДС

Задачи: `NDS-10`, `REP-NDS`, `TAX-NDS-P`

## Сверка до формирования декларации

- [ ] Книга продаж сверена с оборотами по счёту 90 и 91
- [ ] Книга покупок сверена со счётом 19 и с фактически полученными счетами-фактурами
- [ ] По всем вычетам есть счёт-фактура с корректными реквизитами
- [ ] Авансовые счета-фактуры выставлены и зачтены
- [ ] Проведена сверка с контрагентами по счетам-фактурам (через сервис или письмами)
- [ ] Проверена благонадёжность контрагентов с существенными вычетами
- [ ] Разрывы выявлены и отработаны **до** сдачи декларации
- [ ] Проверены операции без НДС и раздельный учёт (если применяется)
- [ ] При наличии ВЭД: импортный НДС подтверждён, экспортная ставка 0% обоснована

## Декларация

- [ ] Контрольные соотношения проверены, ошибок нет
- [ ] Сумма к уплате сверена с данными учёта
- [ ] Декларация отправлена не позднее внутреннего срока
- [ ] Получена квитанция о приёме и положительный протокол
- [ ] Копия декларации передана клиенту

## Уплата

- [ ] Сумма разбита на три равные части
- [ ] Уплата 1/3 в каждом из трёх месяцев следующего квартала, до 28 числа
- [ ] Перед каждым платежом проверено сальдо ЕНС

## Типовые ошибки

- Разрыв обнаружен из требования ФНС, а не при сверке — вычет снят
- Авансовый счёт-фактура выставлен, но не зачтён при отгрузке — двойное начисление
- Декларация сдана в законный срок день в день, протокол об ошибке пришёл позже — просрочка
