# Чек-лист: патент и совмещение УСН с ПСН

Задачи: `TAX-PATENT`, `PSN-10`, `PSN-20`, `PSN-30`, `PSN-40`, `PSN-50`

Совмещение УСН и патента — самая частая причина доначислений у ИП.
Слетевший патент пересчитывается по УСН с начала действия патента, задним числом.

## Оплата патента

| Срок патента | Когда платить |
|---|---|
| До 6 месяцев | Вся сумма до окончания срока действия патента |
| От 6 до 12 месяцев | 1/3 в течение 90 календарных дней с начала действия, остальное до окончания срока |

- [ ] Сроки действия всех патентов клиента выписаны и стоят в календаре
- [ ] Суммы к уплате рассчитаны по каждому патенту отдельно
- [ ] Налог уменьшен на страховые взносы, уведомление об уменьшении подано
- [ ] Платёж прошёл, сальдо ЕНС проверено

## Контроль лимитов — ежемесячно, не раз в год

- [ ] Доход по патенту нарастающим итогом с начала года
- [ ] **При совмещении доходы по УСН и ПСН суммируются** для лимита ПСН — проверено совокупно
- [ ] Средняя численность по патентной деятельности в пределах лимита
- [ ] Общая численность в пределах лимита УСН
- [ ] Нет видов деятельности, запрещённых для патента
- [ ] При приближении к лимиту на 80% клиент уведомлён письменно

Превышение лимита означает утрату права на патент с начала налогового периода,
на который он выдан. Доходы пересчитываются по УСН, налог доплачивается с пенями.

## Раздельный учёт

- [ ] Доходы разделены по режимам: что относится к патентной деятельности, что к УСН
- [ ] Расходы, относящиеся напрямую, отнесены к своему режиму
- [ ] Общие расходы распределены пропорционально доле доходов
- [ ] Методика распределения закреплена в учётной политике и применяется единообразно
- [ ] Сотрудники распределены по видам деятельности, при невозможности — пропорционально
- [ ] Страховые взносы распределены между режимами по той же методике
- [ ] Раздельный учёт подтверждён документально, а не только расчётом на листке

## Книга учёта доходов по патенту

- [ ] Ведётся отдельно от КУДиР по УСН
- [ ] По каждому патенту своя книга, если патентов несколько
- [ ] Доходы отражены кассовым методом
- [ ] Данные книги сходятся с банком и кассой

## Продление на следующий год

- [ ] До 10 декабря проверены сроки окончания действующих патентов
- [ ] Заявление на новый патент подано не позднее чем за 10 рабочих дней до начала применения
- [ ] Просчитано, что выгоднее на следующий год: патент или УСН
- [ ] Клиенту направлен расчёт с рекомендацией

## Типовые ошибки

- Лимит дохода считают только по патенту, забывая прибавить доходы по УСН
- Заявление на новый патент подано позже срока — январь остаётся на УСН
- Общие расходы отнесены целиком на УСН, чтобы уменьшить налог
- Взносы за сотрудников уменьшили оба налога целиком, вместо распределения
- Патент оплачен позже срока — право на режим утрачено
