# Чек-лист: кассовая дисциплина

Задача: `ACC-30`

- [ ] Выгрузка из ОФД получена за весь месяц
- [ ] Данные ОФД сверены с выручкой в учёте, расхождений нет
- [ ] Проверены чеки коррекции и возвраты, по каждому есть основание
- [ ] Проверены смены: все открыты и закрыты, нет смен свыше 24 часов
- [ ] Проверены нефискальные периоды и работа в автономном режиме
- [ ] Кассовая книга ведётся, ПКО и РКО оформлены
- [ ] Лимит остатка кассы соблюдён либо обоснованно не установлен
- [ ] Инкассация и внесение выручки на счёт отражены
- [ ] Расчёты с подотчётными лицами закрыты авансовыми отчётами
- [ ] Наличные расчёты с юрлицами и ИП не превышают установленный лимит по одному договору
- [ ] Эквайринг сверен: сумма по терминалу, зачисление на счёт, комиссия банка
- [ ] Проверен срок действия фискального накопителя

## Типовые ошибки

- Выручка по ОФД больше, чем в учёте — незадекларированный доход
- Возврат оформлен без чека коррекции
- Эквайринг учтён за вычетом комиссии банка — занижен доход
- Фискальный накопитель истекает в отчётном периоде, клиент не предупреждён
