# Чек-лист: планирование месяца

Задача: `INT-30`, исполняет руководитель отдела, срок — 25 число

## Актуализация данных

- [ ] Ведущие бухгалтеры подтвердили актуальность профилей своих клиентов
- [ ] Новые клиенты добавлены в справочник
- [ ] Приостановленные и ушедшие клиенты переведены в `paused` / `archived`
- [ ] Изменения режимов, НДС, численности внесены
- [ ] Изменения ответственных внесены

## Генерация и проверка

- [ ] План сгенерирован: `python3 tools/generate_plan.py --month <месяц> --clients data/clients.csv`
- [ ] Открыта сводка `out/plan_*.md`, проверена нагрузка по сотрудникам
- [ ] Ни у кого нет свыше 130 плановых часов
- [ ] Проверено число задач по новым клиентам — перечень выглядит полным
- [ ] Учтены отпуска и известные отсутствия, задачи переназначены заранее

## Распределение

- [ ] Перегруженные разгружены, задачи переданы с уведомлением обеих сторон
- [ ] Задачи по клиентам отсутствующих сотрудников переназначены
- [ ] Клиенты уведомлены о временной смене ответственного

## Загрузка

- [ ] Задачи загружены в CRM до 27 числа
- [ ] Количество задач в CRM сверено с количеством строк в плане
- [ ] Внеплановые задачи прошлого месяца перенесены или закрыты
- [ ] Каждый бухгалтер подтвердил, что видит свой план

## Передача дел при отпуске

- [ ] Список клиентов и статус по каждому передан подменному
- [ ] Открытые вопросы клиентов зафиксированы письменно
- [ ] Незакрытые периоды и известные проблемы перечислены
- [ ] Доступы проверены у подменного
- [ ] Клиенты уведомлены с контактами подменного бухгалтера
