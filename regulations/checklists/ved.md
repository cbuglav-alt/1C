# Чек-лист: ВЭД

Задача: `ACC-40`

## Валютный контроль

- [ ] Контракты, подлежащие постановке на учёт в банке, поставлены
- [ ] Уникальные номера контрактов получены
- [ ] Справки о подтверждающих документах поданы в срок
- [ ] Сроки репатриации валютной выручки соблюдены
- [ ] Запросы банка по валютному контролю отработаны

## Учёт

- [ ] Валютные счета переоценены на конец месяца
- [ ] Курсовые разницы отражены, курс ЦБ на верную дату
- [ ] Авансы в валюте не переоцениваются — проверено
- [ ] Таможенные декларации проведены, таможенные платежи распределены на стоимость товара
- [ ] Импортный НДС уплачен и подтверждён для вычета
- [ ] При импорте из ЕАЭС: заявление о ввозе и косвенные налоги в срок
- [ ] При экспорте: комплект документов для подтверждения ставки 0% собран, сроки под контролем
- [ ] Учтены агентские обязанности по НДС и налогу на прибыль при работе с иностранными поставщиками услуг

## Типовые ошибки

- Контракт не поставлен на учёт в банке — штраф по валютному законодательству
- Ставка 0% не подтверждена в срок — начисление НДС по общей ставке
- Аванс в валюте переоценён — искажена себестоимость
- Забыли об обязанностях налогового агента при оплате иностранных услуг
