# Чек-лист: сбор и обработка первички

Задачи: `DOC-10`, `DOC-20`, `DOC-40`

## Запрос документов (1 число)

- [ ] Отправлен запрос на согласованный адрес клиента со списком за прошлый месяц
- [ ] В запросе указан срок — до 5 числа
- [ ] Проверено, что банковская выписка загружается по интеграции; если нет — запрошена отдельно
- [ ] Запрошен табель и данные по отсутствиям (если есть сотрудники)

## Приём и обработка

- [ ] Банковские выписки загружены за все счета клиента, включая валютные и эквайринг
- [ ] Документы из ЭДО приняты и подписаны, отклонённые — разобраны
- [ ] Бумажные документы отсканированы и прикреплены к документам в 1С
- [ ] Проверены реквизиты: наименования, ИНН, суммы, ставка НДС, номера и даты
- [ ] Проверены подписи и печати там, где они требуются
- [ ] Счета-фактуры сверены с актами и накладными по суммам и датам

## Контроль полноты (8 число)

- [ ] Сверены обороты по банку с проведёнными документами реализации и поступления
- [ ] Проверено, что по каждому платежу поставщику есть закрывающий документ
- [ ] Проверено, что по каждому поступлению на счёт есть реализация или аванс
- [ ] По новым контрагентам запрошены договоры и проведена проверка благонадёжности
- [ ] Сформирован реестр недостающих документов
- [ ] Реестр отправлен клиенту письмом (не в мессенджер)

## Типовые ошибки

- Документ принят с ошибкой в реквизитах и обнаружен только при сдаче декларации
- Скан приложен, оригинал не запрошен — при проверке подтвердить расход нечем
- Реестр недостающих отправлен в мессенджер: при споре следа нет
- Валютный счёт забыт при сверке оборотов
