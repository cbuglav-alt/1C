# Чек-лист: отправка и контроль отчётности

Задачи: все `REP-*`, `QC-20`

## Перед отправкой

- [ ] Отчёт сформирован за верный период и по действующей форме
- [ ] Проверены контрольные соотношения, ошибок нет
- [ ] Показатели сверены между формами: 6-НДФЛ с РСВ, РСВ с персведениями, бухотчётность с декларациями
- [ ] Данные сверены с предыдущим отчётным периодом, отклонения объяснимы
- [ ] Реквизиты верны: ИНН, КПП, ОКТМО, код периода, код инспекции
- [ ] Проверен срок действия ЭЦП и доверенности / МЧД
- [ ] Отчёт согласован с клиентом, если требуется по регламенту

## Отправка

- [ ] Отправлено не позднее внутреннего срока
- [ ] Получена квитанция о приёме
- [ ] Получен положительный протокол проверки
- [ ] Копия отчёта и протокол приложены к задаче в CRM
- [ ] Копия передана клиенту

## Если пришёл отрицательный протокол

- [ ] Ошибка разобрана в день получения
- [ ] Корректировка отправлена до истечения законного срока
- [ ] Если законный срок уже прошёл — инцидент, уведомление клиента, эскалация
- [ ] Причина ошибки внесена в разбор месяца

**Задача считается выполненной только при наличии положительного протокола.**
Отправленный, но не принятый отчёт — это несданный отчёт.

## Контроль квитанций (28 числа)

- [ ] По всем отчётам месяца получены квитанции и протоколы
- [ ] Отчётов без протокола не осталось
- [ ] Все требования и уведомления из личного кабинета просмотрены и отработаны
