# Чек-лист: выборочный контроль качества

Задача: `QC-10`, исполняет главный бухгалтер

## Полнота задач

- [ ] Профиль клиента в карточке соответствует фактическому положению дел
- [ ] Все задачи месяца закрыты либо имеют объяснённый статус
- [ ] Нет задач, отменённых без обоснования
- [ ] Нет задач, висящих в «Ждёт клиента» свыше 10 рабочих дней

## Качество учёта

- [ ] Оборотно-сальдовая ведомость не содержит подозрительных остатков
- [ ] Счёт 68.90 сходится с данными личного кабинета ФНС
- [ ] Расчёты с сотрудниками сходятся с расчётной ведомостью
- [ ] Выборочно проверены 3–5 документов месяца: реквизиты, суммы, проводки, скан приложен
- [ ] Проверена корректность применения налогового режима и ставок

## Отчётность

- [ ] По всей отчётности периода есть положительные протоколы
- [ ] Показатели между формами сходятся
- [ ] Корректировочных отчётов не было либо их причина разобрана

## Сервис

- [ ] Отчёт клиенту отправлен в срок и по форме
- [ ] Обращения клиента отвечены в рамках SLA
- [ ] Нет неотвеченных вопросов старше 5 рабочих дней

## Результат

- [ ] Замечания зафиксированы в задаче с указанием существенности
- [ ] Существенные замечания разобраны с бухгалтером лично
- [ ] Системные замечания вынесены на месячный разбор и привели к правке каталога или чек-листа
