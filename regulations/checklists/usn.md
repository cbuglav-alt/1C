# Чек-лист: УСН

Задачи: `TAX-USN-N`, `TAX-USN-P`, `REP-USN-OOO`, `REP-USN-IP`

## Контроль лимитов (ежемесячно, не раз в год)

- [ ] Доход нарастающим итогом сверен с лимитом применения УСН
- [ ] Проверен порог, с которого возникает обязанность по НДС
- [ ] Средняя численность сотрудников в пределах лимита
- [ ] Остаточная стоимость основных средств в пределах лимита
- [ ] Нет запрещённых для УСН видов деятельности и филиалов
- [ ] Доля участия юридических лиц в пределах лимита

При приближении к любому лимиту на 80% — уведомить клиента письменно
и вынести вопрос на налоговое планирование.

## Расчёт авансового платежа

- [ ] Доходы определены кассовым методом, включая эквайринг, взаимозачёты, возвраты
- [ ] Для «доходы минус расходы»: расходы проверены на попадание в закрытый перечень
- [ ] Все расходы документально подтверждены и оплачены
- [ ] Для «доходов»: налог уменьшен на страховые взносы в пределах лимита
- [ ] Для ИП без сотрудников: учтено уменьшение на фиксированные взносы
- [ ] Для «доходы минус расходы»: проверен минимальный налог 1% по итогам года
- [ ] Учтён убыток прошлых лет (только по итогам года)
- [ ] КУДиР актуальна и соответствует расчёту

## Уведомление и уплата

- [ ] Уведомление подано до 25 числа месяца, следующего за кварталом
- [ ] Верные КБК, ОКТМО, код периода
- [ ] Сальдо ЕНС достаточно для списания
- [ ] По итогам года: декларация и уплата в срок, зависящий от ОПФ

## Типовые ошибки

- Лимит по доходу проверяется в декабре, когда уже поздно
- В доход не включён эквайринг в полной сумме (взяли за вычетом комиссии банка)
- Расход принят вне закрытого перечня
- Уменьшение на взносы применено сверх лимита
