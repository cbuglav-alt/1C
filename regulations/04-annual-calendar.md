# Годовой календарь

Карта года: что происходит в каждом месяце и где пики нагрузки.
Точные даты с учётом переносов считает генератор — здесь общая картина для планирования
отпусков, найма и приёма новых клиентов.

## Постоянный месячный контур (есть в каждом месяце)

| Число | Задача | Код |
|---|---|---|
| 1 | Запрос первички за прошлый месяц | `DOC-10` |
| 2 | Табель, расчёт зарплаты за прошлый месяц, расчётные листки | `HR-10`, `PAY-20`, `PAY-30` |
| 3 | Уведомление по НДФЛ за 23 – последнее число прошлого месяца | `TAX-NDFL-N2` |
| 5 | Уплата НДФЛ за 23 – последнее число прошлого месяца | `TAX-NDFL-P2` |
| 8 | Банковские выписки, контроль поступления первички | `ACC-10`, `DOC-20` |
| 12 | Проведение документов, касса, эскалация по недостающим | `ACC-20`, `ACC-30`, `DOC-30` |
| 15 | Закрытие месяца в 1С, уплата взносов на травматизм | `ACC-50`, `TAX-SFR-P` |
| 18 | Контроль сальдо ЕНС | `ACC-70` |
| 20 | Отчёт клиенту | `CLI-10` |
| 25 | Уведомление по НДФЛ (1–22), уведомление по взносам, персведения, ЕФС-1 п. 1.1 | `TAX-NDFL-N1`, `TAX-SV-N`, `REP-PS`, `HR-30` |
| 25 | Планирование задач на следующий месяц | `INT-30` |
| 28 | Уплата НДФЛ (1–22), страховых взносов, 1/3 НДС | `TAX-NDFL-P1`, `TAX-SV-P`, `TAX-NDS-P` |
| 28 | Контроль квитанций по отправленной отчётности | `QC-20` |

Зарплатные сроки привязаны к дням выплат из карточки клиента: аванс — `advance_day`,
зарплата — `salary_day`. Расчёт ставится за 2 рабочих дня до выплаты.

## Правила, вытекающие из календаря

**Отпуска.** Основные отпуска планируются на май, июнь, август, сентябрь, ноябрь.
В январе, марте, апреле, июле, октябре отпуск согласовывает руководитель отдела
и только при наличии подменного бухгалтера с брифингом.

**Новые клиенты.** Приём клиента в пиковый месяц требует согласования руководителя отдела:
онбординг занимает 15–20 часов, которых в пик нет. Рекомендуемые месяцы старта —
май, июнь, август, сентябрь, ноябрь.

**Найм.** Нанимать и обучать людей нужно в спокойные месяцы, чтобы к пику человек
уже вёл клиентов самостоятельно. Практический срок ввода в строй — 2 месяца.

**Декабрь, особый порядок по НДФЛ.** За период с 23 по 31 декабря уведомление и уплата
НДФЛ приходятся на последний рабочий день года, а не на январь. Проверяйте этот пункт
отдельно: он не укладывается в общий шаблон и каждый год даёт просрочки по рынку.

## Сезонное распределение нагрузки

```
Часов                                                                  
 270 │ ██        ██                    ██              ██              
 240 │ ██        ██  ██                ██              ██        ██    
 210 │ ██  ██    ██  ██                ██              ██        ██    
 180 │ ██  ██    ██  ██  ██  ██        ██  ██  ██      ██  ██    ██    
     └───────────────────────────────────────────────────────────────
       янв фев мар апр май июн июл авг сен окт ноя дек
```

Разброс между пиком и спадом — примерно в 1,5 раза. Это означает, что штат,
рассчитанный по среднему, в пик работает в переработку. Планируйте ресурс по пику
или выносите часть пиковых задач (первичка, архив) на ассистентов и аутсорс.
